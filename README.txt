FRESHER PORTFOLIO WEBSITE
=========================

FILES
- index.html : page content
- style.css  : styling and responsive layout
- script.js  : mobile navigation, reveal animations, rotating role, footer year

RUN LOCALLY
1. Extract the ZIP folder.
2. Open index.html in a browser (Chrome, Edge, Firefox).
3. To run with the VS Code debugger, open this folder and press F5, then select "Run Portfolio". This opens index.html directly; no local server is required.
4. For editing, open the folder in VS Code. Optional: use the Live Server extension.

CUSTOMIZE BEFORE PUBLISHING
1. Search for "Your Name" / "yourname" and replace with your name.
2. Update the email address (your.email@example.com), city, degree, college, and dates.
3. Update GitHub and LinkedIn links.
4. Replace each sample project with your own project title, description, demo URL, and source-code URL.
5. Adjust skill names and progress widths to honestly reflect your skills.
6. The resume button can be added by placing your resume PDF in this folder and linking it with an <a download> link.

PUBLISH
- GitHub Pages: create a repository, upload these files, then enable Pages in repository Settings.
- Netlify: drag the extracted folder into Netlify's manual deploy area.
- This is a static site; no backend or build step is required.

NOTE
The sample project links use # placeholders. Replace them with real URLs before sharing your portfolio.
